# DrGymGirly

A .NET MAUI starter app for iOS and Android that displays a user's scheduled workout and stores its data locally in SQLite.

## Included

- Native MAUI targets for Android, iOS, Mac Catalyst, and Windows.
- A local SQLite database in the app's private storage.
- A seeded Monday workout for a temporary `demo-user`.
- Separate weekly prescriptions, allowing weights and reps to change without changing the programme structure.

## Run it

Open `DrGymGirly.sln` in Visual Studio, select a target, and run. iOS builds require a paired Mac with Xcode.
